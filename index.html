v4 · Token 架构

三层结构：原始色板 → 语义 token → 组件。 语义 token 存的是 HSL 通道值，所以可以直接写透明度修饰符 hsl(var(--cathi-primary) / .14)， 组件里不出现任何硬编码颜色。切到暗色只是换一组变量值。

语义 token（成对出现）
--cathi-background / --cathi-foreground
--cathi-card / --cathi-card-foreground
--cathi-primary / --cathi-primary-foreground
--cathi-muted / --cathi-muted-foreground
--cathi-accent / --cathi-accent-foreground
--cathi-destructive / --cathi-destructive-foreground
把鼠标放到色块上，颜色随主题实时变化（变量驱动，非固定值）。
透明度修饰符 / α
8% 16% 28% 45% 100%
同一个 token 派生出一整套层级，不需要维护 -soft 变量。
.my-chip {
  background: hsl(var(--cathi-primary) / .14);
  color: hsl(var(--cathi-mint-700));
  border: 1px solid hsl(var(--cathi-border));
}

为什么改成 HSL 通道值？▾
因为这样可以写 hsl(var(--x) / .14)，一个变量派生出整套明暗层级，不用再维护一堆 -soft。
旧代码会坏吗？▾
绝大多数不会。--cathi-bg / --cathi-text / --cathi-surface 等别名全部保留，只有 --cathi-primary 和 --cathi-border 变成通道值，需要包一层 hsl()。
暗色模式怎么开？▾
在任意祖先元素加 .cathi-dark、.cathi-theme-dark 或 data-theme="dark" 即可，不随系统自动切换（和 shadcn 的 class 策略一致）。
